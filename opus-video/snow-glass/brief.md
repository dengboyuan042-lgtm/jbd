# brief.md — Snow Glass

> 这份文件就是这支视频的完整提示词（xilo-opus-video 的七块结构），也是可以直接复用的版本：
> 换主题、换文案、换画幅，改 `<inputs>` 和 `<structure>` 就够了。
> 本次确认的方案：**方案 A · 锁屏（Lock screen）**。

```text
<role>
你是一位动态设计师，也是一位创意程序员，擅长用代码做出有设计感的视频。
你熟悉苹果的 Liquid Glass / 毛玻璃材质：模糊、饱和度提升、边缘高光、内阴影、镜面扫光，
也熟悉「下雪」这件事在镜头里应该怎么被看见——不是满屏白点，而是有景深、有落在玻璃上、
有融化下滑的那几颗。
</role>

<inputs>
主题：一块苹果风格的毛玻璃面板，立在冬夜的雪里。
想让观众记住的一句话：玻璃是有厚度的，雪落在上面会停一下，然后滑走。
原材料：无（纯原创，没有参考视频、没有品牌素材）
规格：12 秒，1080×1920（9:16 竖屏），30 fps
品牌：不适用。配色只用一套：夜空 #03060C / #0C2135 / #1D4058，
        冷光 #A8D6FF，暖光 #FFB976，玻璃白 rgba(226,242,255,0.06–0.14)
字体：Inter（200/300/400/500/600 五个字重，@font-face 本地加载，不联网）
声音：配乐代码合成（无固定 BPM，慢板 3 段和弦 F–A–D，无鼓点），
      音效 = 玻璃风铃，落在雪花碰到玻璃的那一帧；不配音
</inputs>

<direction>
风格：苹果发布会级别的「材质特写」。深色冬夜，背景全部失焦，只有毛玻璃是清楚的；
      光从左上暖、右上冷，玻璃把这些光糊成一片奶油。
      颜色克制到只有蓝黑 + 一点点暖橙，没有任何渐变标题、没有任何彩色图标。
整片只用一套配色、一套材质；同一块玻璃在每个镜头里的边缘高光方向一致（左上亮、右下暗）。
动画全部用弹簧或缓动，没有匀速运动；转场从画面里长出来（推镜、面板弹入），没有淡入淡出式换场。
镜头：一镜到底的缓慢推近（全片 1.00 → 1.13 倍），加一点极慢的横移和呼吸感浮动；
      主体（玻璃面板）始终占画面宽度约 85%、高度约 47%。
禁止：深色背景 + 居中大字 + 渐变的默认海报风；满屏小字；所有元素同时淡入；
      彩色霓虹描边；给玻璃加生硬的白色描边框；用图片素材冒充材质。
</direction>

<structure>
时间轴（无节拍网格，按情绪排；音效时间点与画面事件逐帧对齐）
镜头 1｜0.00–1.20s　黑场 → 冬夜
画面：几乎全黑，只有极暗的蓝。背景先出现（雪、树影、灯串的散景）。
动作：全局从黑场淡入（0–1.15s）；镜头已经开始极慢推近。
声音：风噪淡入；0.32s 一声闷响（玻璃入场）。
转场：无，直接进入镜头 2。

镜头 2｜0.32–2.30s　玻璃落位
画面：一块 912×900、圆角 80 的毛玻璃面板从下方弹簧升起（w=13, z=0.72），
      带 0.945 → 1.0 的缩放；面板底下是压暗的投影。
动作：面板到位后，左上角天气行（雪花图标 + −3° + SNOW）在 1.20s 淡入上浮。
声音：0.32s 闷响；2.40s 第一颗雪落地（风铃）。
转场：面板停稳后，时钟开始进场。

镜头 3｜1.05–4.60s　时间显形
画面：19:42，208px，Inter 500，字符逐个用弹簧从下方带遮罩升起来（每字间隔 0.07s）。
      1.70s 日期 SATURDAY 24 JANUARY（25px，字距 5.8）淡入；
      2.15s 一条渐变细线和底部两行小字（SNOW UNTIL 23:00 / 12 CM），右侧对齐。
动作：整块面板上有一次镜面扫光（2.30–4.30s），从左上扫到右下，像有人从窗前走过。
声音：1.9s、3.1s、4.4s 三声风铃（与雪花落点同步）。
转场：扫光结束的那一刻，通知卡片从面板下沿弹出来。

镜头 4｜5.10–9.00s　第二块玻璃
画面：一张 796×184 的通知卡片，自己的毛玻璃材质（模糊更强、色调更亮），
      从下方弹簧升起，压在面板下沿之上，卡片下方还有一层被它照亮的地面反光。
      内容：雪花 App 图标（蓝渐变 + 白色雪花）+ Weather / Snow continues until 23:00 / NOW。
动作：卡片就位后（约 6.2s 静止），9.00s 起有一次扫光掠过卡片。
声音：5.10s 一声闷响（第二块玻璃落位）；6.4s、7.2s、8.1s、8.9s 四声风铃。

镜头 5｜8.60–12.00s　收尾
画面：左下角出现极淡的字标 SNOWFALL · −3°，右下 24 JAN 2026（20px，字距 4.5，透明度 0.34）。
动作：镜头继续推到 1.13 倍；雪一直在下（三层景深，最前一层是虚化的大雪片）。
声音：最后一颗风铃 8.9s；音乐收在 11.2s，风声淡出到 12.0s。
转场：12.0s 切黑。
</structure>

<build>
1. 画面：纯 Canvas 2D，一个 HTML 文件 + 一个场景库，不用任何外部图片和素材。
   毛玻璃 = 把背景以 1/3 分辨率采样 → blur + saturate + brightness → 拉伸 1.06 倍回填到裁剪区
   （这一步同时做出了「折射放大」和「磨砂颗粒」）→ 叠奶白底色 / 顶部高光 / 底部厚度阴影 /
   反射窗影 / 细噪点 / 镜面扫光 / 内圈高光 / 外圈渐变描边 + 轻微色散。
   背景 = 半分辨率绘制一次并缓存：夜空渐变、月光、暖光、54 个散景光斑、12 盏灯串、
   两排模糊松树、地面积雪；雪花另用三层（远景小、中景实、近景虚）由 t 解析计算位置。
2. 页面暴露 window.render(t)，画出第 t 秒；所有画面只由 t 算出来，随机数用固定种子的
   mulberry32，不用计时器、不保存帧间状态。弹簧用闭式解，任意一帧都能单独重渲。
3. 渲染：Node + @napi-rs/canvas（与浏览器 Canvas 2D 同一套绘制语义）逐帧绘制，
   raw RGBA 直接管道给 ffmpeg（libx264, crf 18）合成 MP4；1080×1920 定时 30fps。
   场景在 1080×1920 设计空间里作画，输出尺寸整体等比缩放，所以 540×960 小样构图完全一致。
4. 声音：numpy 从零合成——pad（F–A–D 三段和弦，微失谐 + 泛音）、两条粉红噪声风声、
   旋律钟、玻璃风铃（8 声，时间点直接抄画面里雪花落地的时刻）、两次低频闷响；
   FFT 卷积混响 2.6s；整体归一化到 −14 LUFS、峰值 −1.5 dBTP。
5. 每做完一个镜头渲 3 张静帧自己检查：文字溢出、元素重叠、主体大小、文字停留时间；
   全部完成后渲整片，再出抽帧图验收。
</build>

<gotchas>
- 字体必须先注册/加载完再截图，否则前几帧是系统默认字体（Node 里 GlobalFonts 注册，
  浏览器里 document.fonts.load 之后才 render）。
- @napi-rs/canvas 的 ctx.filter 支持 blur/saturate/brightness，但每帧对全屏做模糊会慢 7 倍；
  所以背景只画一次、毛玻璃在 1/3 分辨率上模糊，单帧从 695ms 降到 ~110ms。
- 竖屏 9:16 里 1080 宽的布局，任何 < 64px 的字缩到手机上都看不清，所以正文最小 20px
  （等于 1080 宽里的 20px），标题必须 ≥ 78px。
- 雪花落在玻璃上要「先停一下再滑」，加速度不是常数：滑落距离用 after² 的二次曲线，
  尾巴长度要截断，否则会出现一条像划痕一样的白线。
- 通知卡片和面板都是玻璃，两块叠在一起时，卡片的模糊要更强、色调更亮，否则分不清层次。
- 片尾 12s 切黑，但音频留到 12.0s 才收干净，否则最后 0.3 秒会「啪」一声。
</gotchas>

<start>
按镜头顺序制作，每个镜头完成后先出静帧检查；全部完成后渲染整片，出一张抽帧图验收，再交付。
</start>
```

## 工程结构

```
opus-video/snow-glass/
  scene/lib.js        材质、背景、雪、玻璃 —— 全片的「物理」
  scene/scenes.js     三个方案的镜头（a 锁屏 / b 微距 / c 穿行）
  scene/render.js     逐帧渲染器（Node + @napi-rs/canvas → ffmpeg）
  index.html          浏览器里的实时预览，可切方案、拖动时间轴
  audio/make_score.py 配乐合成
  fonts/              Inter 五档字重（本地，不联网）
  previews/           三个方案的预览
  renders/            成片 MP4
  qa/                 抽帧图、音量图、自检记录
```
