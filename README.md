# VECTRA · 交互式数学实验室

一个无需构建工具的单页教学实验室，用可视化方式探索概率、流场、矢量场与函数。

## 运行

直接用浏览器打开 `index.html`，或在仓库根目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 实验模块

- **概率模拟**：掷骰子 / 抛硬币、试验次数、实时直方图、理论概率线、速度与重置。
- **流场艺术**：确定性噪声场、速度 / 轨迹 / 粒子密度、配色、随机种子、暂停与 PNG 导出。
- **矢量场**：编辑 P(x, y) 与 Q(x, y)、预设、箭头密度、箭头 / 流线 / 粒子显示、悬停读数。
- **函数绘图**：多函数、示例、网格、缩放、拖拽平移、光标坐标与输入错误提示。
